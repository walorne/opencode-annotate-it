# Annotate it (OpenCode)

Плагин для OpenCode Desktop: **разметка и ревью** прямо в чате и в документах из правой панели.
Порт [dsh-annotate-it](https://github.com/walorne/dsh-annotate-it) (MIT) для DeepSeek Harness.

Выделил фрагмент → быстрый ответ (Да / Нет / Докажи / Что-то ещё? / Подумать) или свой комментарий
(текстом или диктовкой) → цитата встаёт в очередь композера → `Enter` отправляет всё ревью одним сообщением.

## Что умеет

- Два режима на каждую сессию: **ожидание** (кнопка «Рецензировать» над композером, встроенное
  цитирование OpenCode не трогается) и **рецензирование** (быстрая панель на выделении, подсветка,
  карточки заметок). Переключение: кнопка, `⌘⇧A` / `Ctrl+Shift+A`, команда `/annotate`.
- Аннотирование текста в **чате**, в **документах** правой панели (markdown, код, CSV, mermaid,
  diff-просмотр), в **терминале** (выделил → `⌘C` → панель) и в **браузер-панели** (выделение
  подхватывается автоматически).
- Быстрые ответы + свой комментарий; словарь редактируется прямо из панели
  (правый клик по чипу → изменить/удалить, «+» — добавить).
- Оранжевая подсветка отмеченных фрагментов: ярче — неотправленные, бледнее — отправленные.
  Карточка с историей комментариев при наведении, добавление комментариев и удаление заметки.
- Очередь цитат — нативные чипы композера OpenCode; отправка одним сообщением — нативная.
- Диктовка (Web Speech API) в поле комментария; где распознавания нет — подсказка про системную
  диктовку (macOS: 2×Fn).
- Заметки, режим и словарь хранятся локально (сторы плагина), никуда не отправляются.

## Отличия от версии для DeepSeek Harness

- PDF и Office в правой панели OpenCode рендерятся в изолированном фрейме — выделить текст там
  нельзя; аннотируются markdown/код/таблицы/diff.
- Терминал — canvas (ghostty): выделение не видно из DOM, поэтому триггером служит копирование
  (`⌘C`): скопированный текст сразу предлагается для аннотации.
- Браузер-панель опрашивается main-процессом раз в 400мс; подсветка заметок внутри страницы
  невозможна (изолированный webview), но цитата с URL источника сохраняется.
- Лента ревью — нативные чипы композера (с именем источника у каждой цитаты), а не отдельная
  лента над полем ввода.
- Если удалить чип цитаты вручную (крестиком на чипе), заметка в подсветке остаётся, пока её не
  удалить через карточку или «Очистить всё».

## Установка

Одной строкой, как в DSH (после публикации репозитория):

```sh
opencode plugin add github:walorne/opencode-annotate-it
```

Или локально — в `~/.config/opencode/opencode.jsonc`:

```jsonc
{
  "plugins": ["/Users/pastakhov/Documents/DEV/opencode-annotate-it"]
}
```

## Настройки

Settings → Annotate it: карандашик при выделении, подсветка, словарь быстрых
ответов, горячие клавиши (`⌘⇧A` — режим рецензирования; переназначается в
Settings → Shortcuts).

## Разработка

```sh
npm install
npm run build     # или npm run watch — пересборка перезагружает GUI во всех окнах
npx tsc --noEmit
```

GUI-часть (`./gui-experimental`) собирается Vite-пресетом `@opencode/plugin/gui/vite` в один
CommonJS-файл. Целевая версия SDK — 2.3.x (OpenCode Desktop 2.3.0).
